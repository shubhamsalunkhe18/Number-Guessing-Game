# 🎯 Number Guessing Game (Java)

## 📖 Project Overview
This is a console-based Number Guessing Game developed using Java.  
The program generates a random number within a specific range, and the user has to guess the correct number.  
The system provides hints such as "Too High" or "Too Low" until the correct number is guessed.

---

## 🚀 Features
- Random number generation
- User input using Scanner
- Hint system (Too High / Too Low)
- Loop until correct guess
- Displays number of attempts

---

## 🛠 Technologies & Concepts Used
- Java
- Random class
- Loops (while loop)
- Conditional statements
- Scanner class

---

## ▶️ How the Game Works
1. The program generates a random number (for example between 1–100).
2. The user enters a guess.
3. If the guess is:
   - Greater than the number → "Too High"
   - Less than the number → "Too Low"
4. The game continues until the correct number is guessed.
5. The total number of attempts is displayed.
